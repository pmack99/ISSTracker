## Description (max 4,000)

```
Track the International Space Station from your iPhone.

ISS Tracker shows the station’s live position on a hybrid map with a smooth-moving marker and optional follow mode. Expand the Live tab dock for orbit details, who’s on board the ISS, and NASA cabin telemetry. Search visible passes for the next 10 days using your city, ZIP code, or current location—then open pass details with compass direction and elevation to help you spot the ISS in the sky.

FEATURES
• Live map — ISS position with smooth motion (network refresh about every 30 seconds while the app is open)
• Live dock — orbit readout, crew list, cabin environment (pressure, temperature, water, CO₂)
• Overhead passes — visible pass predictions for your location
• Pass reminders — local notifications before a pass (your choice)
• Live Activity — optional pass countdown on Lock Screen and Dynamic Island (supported devices)
• Compass assist — heading help on pass detail
• Saved places — star a default location for quick searches and reminders
• Search history — stored on your device
• NASA gallery — browse ISS photos from NASA’s public library

DATA & PRIVACY
No account required. Pass history and saved places stay on your device. Location is used only when you ask for pass predictions based on “current location.” See our privacy policy for third-party APIs (Where The ISS At, ISS Tracker API, Open Notify, NASA ISSLIVE, Apple Maps, NASA images).

ISS Tracker continues an open-source project from the UCF Coding Bootcamp, rebuilt as a native SwiftUI app with MapKit.

Support: https://pmack99.github.io/ISSTracker/support.html
Privacy: https://pmack99.github.io/ISSTracker/privacy.html
```

## Review notes for Apple

```
ISS Tracker does not require sign-in or a demo account.

HOW TO TEST:
1. Open the Live tab — ISS position loads from “Where The ISS At” (internet required). Optional: open LIVE / CREW / CABIN in the bottom dock.
2. Open Passes — enter a city or ZIP (e.g. “Orlando, FL” or “32801”) and search; pass list loads from the ISS Tracker API.
3. Optional: allow Location When In Use and search using current location.
4. Optional: allow Notifications when prompted after scheduling passes from a search.
5. Live Activity: open a pass → enable “Show Live Activity for this pass” (physical iPhone recommended).

No special hardware is required. The app is iPhone-only, portrait, iOS 17+.

Support email: 3PMStudios@protonmail.com
Privacy policy: https://pmack99.github.io/ISSTracker/privacy.html
```
