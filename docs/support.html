Requirements

  • iPhone with iOS 17 or later
  • Internet connection for live position and pass predictions
  • Location permission (when in use) for “current location” pass searches
  • Notification permission for pass reminders (optional)

Frequently asked questions

Pass times don’t match what I see

Visible passes depend on sky clarity, city lights, and the station’s brightness. Predictions come from N2YO; a minute or two of difference versus other apps can happen. Try a darker viewing spot and check max elevation (higher is easier to see).

Live map position seems delayed

Position updates about every 30 seconds from Where The ISS At. The marker animates smoothly between updates.

Notifications aren’t firing

Check Settings → Notifications → ISS Tracker. Reminders are scheduled locally when you run a pass search; search again after changing location or if you cleared notifications.

“N2YO API key is missing” (developers)

Pass search needs a personal N2YO key in Config/Secrets.xcconfig. See the README on GitHub.

Widget or Live Activity

Run a pass search for a saved location so the app can publish the next pass to the widget and App Group. Live Activity appears when a pass is synced and supported on your device.
